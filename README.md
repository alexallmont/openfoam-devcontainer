# OpenFOAM VSCode devcontainer

Environment for easy onboarding with OpenFOAM. Currently includes:

- .devcontainer files to build, run and intellisense support.
- Uses `openfoam-default` rather than `openfoam-dev` so tutorials are included.
- Uses 2306+ to support latest platforms, including macOS.

Incoming features:

- `.clang-format` for OpenFOAM standard.
- Debug launch task.
